# Chrome Web Store submission checklist

Version 0.1.1. Nothing in this repository has been uploaded. Do not submit until the unchecked items are done. Screenshots were not created for this change.

## Listing

- [ ] Developer account is registered, and the one-time registration fee is paid if Google still requires it.
- [ ] Item is marked **free**. There is no in-app product.
- [ ] Name: Shouldn't Wouldn't
- [ ] Summary, 131 characters, from `store/listing-short.md`: "Think Twice Before You Share. Free local reminders when a page asks for sensitive information. Nothing you type leaves the browser."
- [ ] Detailed description pasted from `store/listing-detailed.md`, without the file's heading and the "not submitted" note.
- [ ] Category: a privacy or productivity category that matches a reminder extension. Pick the closest current category in the dashboard. Do not add extra keywords to chase search.
- [ ] Language: English.
- [ ] Single purpose, for the privacy form: "Shows a local reminder when a page looks like it is asking for sensitive information, so a person can pause before typing. The reminder is not a verdict that a website is safe."

## Icons and screenshots

The extension already has a 128×128 icon at `icons/icon128.png`, plus 16, 32, and 48. Those were generated by `scripts/make-icons.mjs`. They are not store screenshots.

Google asks for at least one screenshot, 1280×800 (preferred) or 640×400, square corners, no padding. Up to five. Optional promo tiles are 440×280 and 1400×560. Do not draw mock screenshots. Capture the real unpacked extension.

Suggested shots, once someone has loaded the extension:

1. `fixtures/ssn.html` over `http://127.0.0.1:8765`, with the Social Security reminder visible and the comments field quiet.
2. The same page with "Why am I seeing this?" open.
3. The toolbar popup on that page, showing the status and the privacy text.
4. `fixtures/comment.html`, showing an ordinary comment box with no reminder.
5. The popup with protection turned off.

- [ ] At least one real 1280×800 screenshot is captured from the running extension.
- [ ] No screenshot shows a real password, card number, Social Security number, or other personal information.
- [ ] Optional promo images are either real or omitted.

## Privacy form

Host `store/privacy-policy.md` at a public HTTPS URL before submission. The store asks for that URL. This repository does not publish the page for you.

- [ ] Privacy policy URL is live and matches version 0.1.1.
- [ ] The mailbox support@shouldntwouldnt.com receives mail. The address is the one requested for this policy. Delivery was not tested from this environment.
- [ ] Permission justification for host access (`http://*/*` and `https://*/*`): the reminder has to run on ordinary pages so it can read field type, name, id, autocomplete, placeholder, label, and nearby description, plus the hostname, the `http`/`https` scheme, and a warned form's `action`. It does not read what the person types.
- [ ] Permission justification for `storage`: remembers only whether protection is on or off in this browser profile.
- [ ] Remote code: No.
- [ ] Data-use checkboxes match the policy. This extension examines website content locally (field metadata, hostname, and scheme) and stores only the on/off boolean. It does not receive or store typed passwords, card numbers, Social Security numbers, health details, or messages. Check a box only when its label covers that local handling. Do not check a box that means the extension collects those values.
- [ ] Limited-use certification: data is not sold, not used for an unrelated purpose, and not used for credit or lending. The policy already says the Chrome Web Store User Data Policy, including Limited Use, applies.

## Package

- [ ] `npm test` and `npm run build` were run on the package that will be zipped.
- [ ] The zip is the repository root after the build, including `manifest.json`, `dist/`, `icons/`, `popup.html`, `popup.css`, and `content.css`. Leave out `node_modules/`, `store/` drafts are fine to leave out of the zip, and tests are not required in the package.
- [ ] Manifest version is 0.1.1.
- [ ] The package was loaded unpacked and the remaining cases in `store/manual-tests.md` were clicked through. Some fixture and on/off checks were run in Chrome 156 and are recorded there. The toolbar popup, the insecure-connection page, and the suspicious-looking page were not.

## Do not claim

- Do not say Google has reviewed or approved the extension.
- Do not say a website is safe, verified, or a scam.
- Do not say the extension blocks a hostile page from hiding a reminder.
- Do not say the extension is completely secure because the automated tests passed.
